g 粤拼发音速查

核心字词

目标：能够点一杯饮品，并提出冷热、甜度这样的小要求。

6/6 核心字词
A1
冻 dung3 冷的；加冰的
收藏
我要杯冻奶茶。 ngo5 jiu3 bui1 dung3 naai5 caa4. 我要一杯冰奶茶。
A2
少甜 siu2 tim4 少放一点糖
收藏
冻柠茶少甜，唔该。 dung3 ning4 caa4 siu2 tim4, m4 goi1. 冻柠檬茶少甜，麻烦了。
A3
杯 bui1 量词：一杯饮品
收藏
我想要杯热咖啡。 ngo5 soeng2 jiu3 bui1 jit6 gaa3 fe1. 我想要一杯热咖啡。
A4
唔该 m4 goi1 劳驾；麻烦你；接受服务时表示谢谢
收藏
A5
热 jit6 热的饮品
收藏
A6
走冰 zau2 bing1 不加冰
收藏
杯冻奶茶走冰，唔该。 bui1 dung3 naai5 caa4 zau2 bing1, m4 goi1. 这杯冰奶茶不要加冰，麻烦了。
02 · CORE PATTERNS

核心句型

先套用句型，再替换饮品和要求。

我想要杯＋饮品。 ngo5 soeng2 jiu3 bui1 ...

表示“我想要一杯……”。

饮品＋冻／热＋少甜／走冰。 ... dung3 / jit6 ... siu2 tim4 / zau2 bing1

在饮品后补充冷热、甜度或冰量要求。

03 · REAL DIALOGUE

情景对话

把刚学的表达放回一次完整点单。

店员
想饮啲咩啊？
soeng2 jam2 di1 me1 aa3?
想喝点什么？
顾客
唔该，我想要杯冻柠茶，少甜。
m4 goi1, ngo5 soeng2 jiu3 bui1 dung3 ning4 caa4, siu2 tim4.
麻烦来一杯少甜的冰柠檬茶。
店员
要唔要走冰啊？
jiu3 m4 jiu3 zau2 bing1 aa3?
要不要去冰？
顾客
唔使啦，少冰可以。
m4 sai2 laa1, siu2 bing1 ho2 ji5.
不用了，少冰就行。
店员
好，马上来。
hou2, maa5 soeng6 lei4.
好，马上来。
04 · QUICK CHECK

小练习
