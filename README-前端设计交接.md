## 6. 不可自行改变的产品约束

后续前端模型必须遵守：

1. 产品面向普通话使用者和粤语初学者；
2. 学习目标是香港粤语与香港日常交流；
3. 默认显示简体，用户可以切换繁体；
4. 简繁切换只改变字形，不把粤语改写成普通话；
5. 一级导航是首页、基础课程、影视学粤语、收藏和我的学习；
6. 粤拼速查和高频字词属于基础课程，不增加一级模块；
7. 情景对话属于课节内容，不增加一级模块；
8. 视频学习页是产品的核心差异化页面；
9. 电脑端视频学习采用左侧视频、右侧字幕；
10. 移动端采用上方视频、下方字幕；
11. 点击字幕后在原位置展开粤拼和普通话；
12. 单句支持重播和收藏，收藏保留原声时间位置；
13. 游客可以体验内容，保存进度或收藏时再引导登录；
14. MVP 不做用户录音、发音评分、AI对话和用户视频上传；
15. DeepSeek 是内容辅助能力，不在首页增加独立聊天入口；
16. 课程音频统一使用已经确定的 Fish Audio 女声；
17. 正式视频由用户后续提供，目前使用占位内容；
18. 不得为了视觉丰富擅自加入社区、排行榜、积分商城等功能。
